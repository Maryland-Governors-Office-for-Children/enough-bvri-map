# ENOUGH × BVRI Map

Interactive map showing the overlap between ENOUGH Act eligible communities and Baltimore Vacants Reinvestment Initiative (BVRI) activity in Baltimore City.

**Live site:** https://maryland-governors-office-for-children.github.io/enough-bvri-map/

Built for the Maryland Governor's Office for Children. BVRI data from Baltimore City DHCD via Open Baltimore ArcGIS.
