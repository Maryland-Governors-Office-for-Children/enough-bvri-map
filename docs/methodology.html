Map Methodology

Overview

This map overlays four geographic data layers for Baltimore City to help the Maryland Governor's Office for Children (GOC) and the Baltimore Vacants Reinvestment Initiative (BVRI) team see where their work intersects. All data is fetched from publicly available, authoritative sources — no proprietary or licensed datasets are required.

The four layers are:

  • ENOUGH grantee tracts (Maryland GOC)
  • BVRI Vacants to Value properties (Baltimore City DHCD)
  • DHCD Impact Investment Areas (Baltimore City DHCD)
  • NMTC eligibility (US Treasury CDFI Fund)

The full source code, including data-fetch scripts, lives at github.com/Maryland-Governors-Office-for-Children/enough-bvri-map.

Layer 1 — ENOUGH Grantee Tracts

ENOUGH Grantee Tracts — colored by grantee organization

What it shows: The 40 census tracts in Baltimore City currently served by 11 active ENOUGH Act grantees, colored by grantee organization.

Source

Internal GOC data, derived from the master ENOUGH grantee list maintained by the Governor's Office for Children. The grantee → tract assignments come from the FY26 ENOUGH grantee tract roster used in the enough-eligibility-changes repo.

Vintage: FY26 active grantees (current as of May 2026)
Geometry: 2020 Census Tracts (TIGER/Line via Maryland Department of Planning ArcGIS)
Refresh cadence: When new grantees are awarded or geographic scope changes

How it's built

Two source files are combined:

  • grantee_geoids.json — flat list of all ENOUGH grantee tract GEOIDs statewide (108 total)
  • map_filters.json from the eligibility repo — provides the grantee organization name for each tract

The build step filters both to Baltimore City tracts (STCOFIPS=24510), joins them, and writes docs/data/grantee_tracts.geojson with a grantee_name property on each tract feature.

Eligibility note

"Eligible" tracts (i.e. those meeting the ENOUGH Act poverty threshold) and "grantee" tracts are different. A tract is eligible if it meets the ACS child-poverty threshold; a tract is a grantee tract only if a current grantee organization is operating in that geography. Of Baltimore City's 199 tracts, 85 are ENOUGH-eligible and 40 of those are actively served by grantees.

Layer 2 — BVRI Vacants to Value Properties

BVRI Vacant Properties — red dots

What it shows: The 1,192 properties currently on Baltimore City's Vacants to Value open bid list — vacant buildings being marketed for rehab and reinvestment.

Source

Baltimore City Department of Housing & Community Development (DHCD), via the City's public ArcGIS REST service:

https://egisdata.baltimorecity.gov/egis/rest/services/
  Housing/DHCD_Open_Baltimore_Datasets/FeatureServer/7

This is Layer 7 of the DHCD Open Baltimore Datasets feature server — "Open Bid List - Vacants to Value." It's the same backing dataset used by Baltimore City's public Power BI dashboards on demolition, vacant building notices, and rehab activity.

Vintage: Live (refreshed daily by DHCD as properties are added/removed)
Geometry: Point per property
Coverage: Baltimore City only
Refresh cadence: Run python3 scripts/fetch_bvri.py to pull the latest list

BVRI overlap calculation

The "BVRI in Grantee Tracts" stat (currently 387) is computed in the browser via point-in-polygon ray casting: each BVRI property point is tested against each grantee tract polygon; a property is counted as overlapping if it falls within any grantee tract. When a single grantee is selected from the sidebar, the count switches to that grantee's tracts only.

Layer 4 — NMTC Eligibility (CDFI Fund)

NMTC Eligibility — off by default; two distress tiers

What it shows: Census tracts that qualify for the New Markets Tax Credit (NMTC) Program, classified by distress severity. Of Baltimore City's tracts, 115 are in Severe Distress and 28 are Distressed; the rest are not present in the source dataset (= not NMTC-eligible).

Source

US Treasury CDFI Fund's authoritative public ArcGIS feature service, distributed via Esri's federal layer manager:

https://services6.arcgis.com/BAJNi3EgCdtQ1BCG/arcgis/
  rest/services/NMTC_Qualified_Tracts_2020/FeatureServer/3

This is the same dataset that PolicyMap and CDFI's own CIMS mapping tool surface. We use it directly to avoid the PolicyMap subscription requirement and to integrate visually with the rest of the map.

Underlying data: 2016–2020 ACS 5-Year Estimates
Tract geometries: 2020 Census Tracts
Eligibility year: CY 2024
Refresh cadence: CDFI Fund updates this dataset when new ACS vintages are released. Run python3 scripts/fetch_nmtc.py to pull the latest.

Distress classification

The CDFI Fund's source service does not store the distress tier as a single field. Instead, the classification is computed from three underlying metrics. We replicate that logic in scripts/fetch_nmtc.py:

TierCriteria (any of)
Severe Distress Income ≤ 60% of benchmark, or poverty rate ≥ 30%, or unemployment ratio ≥ 1.5× national
Distressed Income ≤ 80% of benchmark, or poverty rate ≥ 20%
Eligible Qualifies as a Low-Income Community but not in either tier above
Insufficient Data All three metrics missing
Not Eligible Does not qualify (excluded from the dataset, not shown on map)

The benchmark for the income test is the higher of the statewide median family income or the metropolitan-area median family income (whichever applies based on OMB Metro/Non-metro designation).

Note on PolicyMap

PolicyMap's NMTC layer ("New Markets Tax Credit (NMTC) Program Eligibility, Deep Distress Status, High Migration Rural County Status, Severe Distress Status, and Non-Metropolitan Status, for CY 2024, using 2016-2020 eligibility data") draws on this same underlying CDFI Fund data. Their additional categories ("High Migration Rural County" and "Non-Metropolitan Status") apply only outside metropolitan areas, so they don't appear in Baltimore City — the city is fully metro per OMB.

Basemap

The map tile layer is CartoDB Positron, served from basemaps.cartocdn.com. Tiles are © OpenStreetMap contributors, © CARTO. No authentication required; CARTO's free tier permits non-commercial public use under the OpenStreetMap ODbL.

Caveats and limits

  • Tract vintages: All four layers use 2020 Census Tracts. ENOUGH eligibility uses 2024 ACS 5-Year (the latest available); NMTC uses 2016–2020 ACS (CDFI Fund's current eligibility cycle). The two ACS vintages don't align perfectly, but tract-level geographic boundaries are the same.
  • Point-in-polygon accuracy: The BVRI overlap counts use simple ray-casting on tract polygons. Properties exactly on tract boundaries can occasionally be misclassified; in practice this affects <1% of points.
  • BVRI dataset scope: The "Vacants to Value" open bid list (~1,192 properties) is one of several Baltimore vacant-property datasets. It does not include vacant building notices, demolitions completed, or properties already in receivership. Those are separate layers in the same DHCD feature server (Layers 0, 1, 2, 4, 5) if needed.
  • NMTC tier coverage: The CDFI Fund's authoritative service excludes ineligible tracts entirely (rather than including them with a "Not Eligible" classification). So a tract with no NMTC-layer fill is simply not in the dataset; we don't render the "Not Eligible" or "Insufficient Data" tiers because they're empty for Baltimore City.
